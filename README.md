# 入稿データチェッカー

Adobe Illustrator 用の入稿データ品質チェック CEP パネル。
テキストアウトライン忘れ・解像度不足・塗り足し不足などを自動検出し、プレビュー上のオーバーレイと検出結果リストで確認できます。

## インストール方法

### ZXP ファイルをインストールする

GitHub Releases から `nyuukou-checker-v1.1.2.zxp` をダウンロードし、以下の手順でインストールします。

1. Adobe Illustrator を完全終了します
2. ZXP Installer を起動します
3. 配布されている `nyuukou-checker-v1.1.2.zxp` を ZXP Installer にドラッグ&ドロップします
4. パスワード入力や許可を求められた場合は、macOS の画面表示に従って続行します
5. インストール完了後、Adobe Illustrator を起動します
6. **ウィンドウ → エクステンション → 入稿データチェッカー** を開きます

### ZXP Installer をまだ入れていない場合

ZXP Installer は第三者が提供するアプリケーションであり、本プロジェクトには同梱されません。入手・インストールは提供元の公式案内に従ってください。

1. <https://aescripts.com/learn/zxp-installer/> を開き、提供元を確認します
2. macOS 版の ZXP Installer を取得・インストールします
3. ZXP Installer の画面へ `nyuukou-checker-v1.1.2.zxp` をドラッグ&ドロップします

macOS のセキュリティ警告が表示され、提供元やファイルの正当性を確認できない場合は、保護機能を無効化せずにインストールを中止してください。

### アンインストール

ZXP Installer のアンインストール機能を使って削除してください。
手動で削除する場合は、以下のフォルダを削除してください。

```text
~/Library/Application Support/Adobe/CEP/extensions/com.git00152.nyuukochecker
```

## 使い方

1. チェックしたい Illustrator ファイルを開きます
2. パネルの「チェック実行」ボタンをクリックします
3. 結果が「要修正」「要確認」「参考」の 3 段階で表示されます（内部の重要度 ERROR / WARNING / INFO に対応）
4. 重要度ボタンと「項目…」で表示する結果を絞り込めます
5. プレビューの拡大縮小、100% 表示、全体表示、選択項目への移動ができます
6. 検出結果グループを展開すると影響と対処が表示されます。項目をクリックするとプレビュー上の該当箇所がハイライトされます
7. 右上の設定ボタンで、大判印刷モード・検出対象・操作の設定を切り替えられます
8. パネルの配色は Illustrator の「ユーザーインターフェイス」の明るさに合わせて切り替わります

### 入稿プロファイル（CMYK入稿 / RGB入稿）

パネル上部の CMYK / RGB の切り替えで、入稿先に合わせた判定基準を選んでからチェックを実行してください。選んだプロファイルは次回起動時も保持されます。

- **CMYK入稿**（既定）: 一般的な CMYK 入稿の基準で判定します。
- **RGB入稿**: グラフィック社の RGB 印刷など、RGB（sRGB / Adobe RGB）のまま入稿する場合の基準で判定します。
  - ドキュメントのカラーモードが RGB でない場合に ERROR（CMYK のままでは RGB 印刷の効果が得られないため）
  - RGB / グレースケール / モノクロ画像はエラーにしません。CMYK 画像は WARNING、それ以外（インデックスカラー・Lab 等）は ERROR
  - インキ総量（350% 超過）・CMYK 小数点のチェックと、Acrobat での TAC 確認は行いません

画像に埋め込まれたカラープロファイル（sRGB / Adobe RGB の混在など）は、現時点では判定しません。入稿先の注文時に選ぶカラースペースと揃っているか、別途確認してください。

### 検査範囲と結果の確認

パス・テキスト・画像の位置に関する検査は、選択中のアートボードだけを対象にします。複数のアートボードがある場合は、プレビュー上のタブを切り替えてからチェックしてください。文書のカラーモード、ラスタライズ効果、非表示レイヤーは共通検査として実行し、非表示オブジェクトは選択中アートボードの範囲に限定します。未使用スウォッチのような文書全体検査は、現行のアートボードチェックでは自動実行しません。

「すべて表示」で絞り込みを解除できます。フィルタに一致する結果がない状態と、検出が0件の状態は区別して表示します。一部の検査が失敗した場合は完了の警告を表示し、検査設定を変更した場合は再チェックを案内します。

配置AI・PDF・EPS・SVGはベクターや複数の画像を含み得るため、配置行列だけで解像度不足とは判定しません。解像度は手動確認として表示します。塗り足し・セーフゾーンは外接矩形を使った推定であり、クリッピング、透明、重なりを含めた印刷結果の保証ではありません。

### 大判印刷モード

大判印刷用ファイルの場合は、設定パネル内の「大判印刷モード」を有効にしてからチェックを実行してください。
画像解像度の判定が大判印刷向けに緩和され、200dpi 以上 300dpi 未満は INFO として扱われます。

### 設定パネル

設定パネルでは、オープンパス検出、塗りありオープンパス検出、トンボレイヤーを検出対象に含めるかどうか、結果選択時のプレビュー自動移動、削除前確認を切り替えられます。ガイドは常に検査対象外です。
チェック設定の変更は次回の「チェック実行」から反映されます。表示・操作設定はその場で反映されます。

### 対象選択と安全削除

一部の検出結果では、カード内の「編集画面で選択」から Illustrator 上の対象を選択できます。
削除アクションは安全のため、孤立点に限定しています。削除直前にも対象を再特定・再判定し、対象が見つからない、複数候補が残る、ロック中である場合は削除しません。
未使用スウォッチは検出のみ行い、パネルからは削除しません。アピアランスの追加塗りやパターン内の特色使用は判定できず、使用中の特色を削除するとプロセスカラーに変換されるためです。整理はスウォッチパネルメニューの「未使用項目を選択」で行ってください。

### Acrobat での TAC 確認

「AcrobatでTAC確認」ボタンを押すと、現在の AI ファイルを保存したうえで Acrobat 確認用 PDF を一時保存し、Adobe Acrobat で開きます。Adobe Acrobat を開けない場合は Adobe Acrobat Reader も試します。

現在の方式はIllustratorの「別名で保存」を使うため、作業中の文書の保存先が一時PDFに切り替わります。確認後に編集を続ける場合は、元のAIファイルを開き直してください。

この機能は、拡張機能内で総インキ使用量を完全判定するものではありません。画像や重なりを含む TAC は、Acrobat Pro の出力プレビューで確認してください。

一時保存された PDF が不要になった場合は、「一時PDFを削除」ボタンで削除できます。
